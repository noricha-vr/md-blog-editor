# ブログエディター

シンプルで使いやすいマークダウンエディターです。

## 機能

- **リアルタイムプレビュー**: マークダウンの編集内容をリアルタイムでプレビュー表示
- **レスポンシブデザイン**: デスクトップ・モバイルどちらでも快適に使用可能
- **履歴機能**: 編集内容を自動保存し、過去の状態に復元可能
- **クリップボード対応**: マークダウンテキストを簡単にコピー
- **画面フル活用**: エディターが画面いっぱいに表示され、ウィンドウリサイズにも対応

## 技術仕様

- **エディター**: TOAST UI Editor
- **スタイリング**: カスタムCSS（モダンなデザイン）
- **データ保存**: ブラウザのLocalStorage
- **デプロイ**: Cloudflare Pages

## 開発・デプロイ

### ローカル開発

```bash
npm install
npm run dev
```

### デプロイ

```bash
npm run deploy
```
